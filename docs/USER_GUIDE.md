# User Guide: Navigating Shravan

## Interface & Navigation
Shravan is designed to be usable with zero vision. Every action provides auditory and tactile confirmation.

### Navigation Methods
1.  **Bottom Bar**: A high-contrast, icon-only bar for quick switching between modes.
2.  **Horizontal Gestures**: Swipe left or right anywhere on the screen content to cycle through pages.
3.  **Global Voice Commands**: Speak naturally to switch modes.
    - **English**: "Explore", "Find", "Text", "Currency", "Settings", "History", "Back".
    - **Vietnamese**: "Khám phá", "Tìm kiếm", "Văn bản", "Tiền", "Cài đặt", "Lịch sử", "Quay lại".

## Operating Modes

### 1. Explore Mode
The default mode. Simply point the camera. Shravan will announce objects in front of you. 
- **Feedback**: Continuous TTS announcements.
- **Tip**: Move the camera slowly for better detection accuracy.

### 2. Find Mode
Used to locate specific items.
- **Sub-Modes**: You can select categories like "Electronic" (Phone, Laptop) or "Obstacle" (Chair, Table).
- **Tactile Proximity**: As you point the camera towards the target object, the vibration pulses will become faster and more intense.

### 3. Currency Mode
Specialized for identifying Vietnamese Dong (VND).
- **Tip**: Ensure the banknote is flat and well-lit. The app will announce the value (e.g., "Five hundred thousand VND").

### 4. OCR Mode (Text Reading)
Reads text in real-time.
- **Usage**: Hold the phone steady over the text. The app will begin reading as soon as it identifies characters.
- **Language**: Supports both English and Vietnamese text recognition.

## Settings & Customization

### The "Factory Reset" Mechanism
To prevent accidental data loss, the Factory Reset button in Settings requires a multi-tap confirmation.
- **Heat Map Effect**: As you tap the reset button, the Navigation Bar progressively turns red. This "Heat Map" provides a clear visual and conceptual warning that a destructive action is about to occur.

### Impairment Level
- **Partially Blind**: Includes visual bounding boxes and high-contrast labels.
- **Totally Blind**: Focuses on optimized voice command polling and prioritized haptics.

### Language
Switching the language instantly updates:
1. All UI labels.
2. The TTS voice engine.
3. The Voice Command recognition engine.
4. The AI labels (e.g., "Chair" becomes "Cái ghế").
