- Supported language: English (default) & Vietnamese, which uses different TTS & speech recognition
- All texts e.g. welcome text, labels, read-out-loud texts etc. are configurable via resource file(s) in dedicated resource (Jetpack COmpose-specific resource folder). The same goes for all configuration values i.e. do not hard-code. Texts should be concise, not verbose.
- All LLMs must require no API key i.e. just download/integrate and use it with no restrictions. 
- Use Inter font
- Use speaker volume (like in calls) isntead of normal audio volume
- App icon is " @illuminati.png". Currently it's placed in the root folder, move it to the right, conventional folder instead.
- For every transition, use proper animations, prioritizing fade in/out where appropriate.

- When user first opens the app, it first asks for every necessary perms. Then, it says some welcome text (during which screen is dimmed, after which it fades to normal) and listen for user speech; as user speaks (stream), a LLM runs inference to clarify their intent; when the intent is clear (e.g. above some threshold), it triggers haptics & cause screen to fade to dimmed (indicating not receiving user input/speech), and speaks something indicating received intent. Intent here refers to whether the user is partially blind or totally blind. Then it redirects to Explore screen.
- When the user opens the app later (after first startup), it opens on Explore screen.
- Explore screen, Find screen, OCR Screen, Currency screen, Settings screen, History screen all has a bar fixed to the bottom of the screen. It has 6 respective icons. Clicking on one of them triggers a haptics and redirects to that screen. Swiping left/right triggers haptics, redirects to the left/right screen using swipe left/right animation (for leftmost/rihtmost screen, swiping left/right has no effect instead). In each of that screen, it listens for user speech; when intent is clear (i.e. it is clear that the user wants to redirect to screen X), it triggers haptics and redirects to that screen.
- Explore screen: Shows camera feed (0.6x len). When an object is detected (i.e. shows in the camera feed), it is surrounded by a bounding box (each bounding box is differently colored, and has label on top; label follows current language), and the app speaks aloud that object's label (follows current language). As long as the object remains in the camera feed, it does not trigger the "detection" (i.e. the object's name does not get spoken a second time).
- Find screen: Shows camera feed (0.6x len). It first shows a monotone version of the camera feed while listen for user speech; when intent is clear, it triggres haptics & cause camera feed to fade to normal coloring. Intent here refers to the following mode: find seatings & tables, find doors & windows, find person & vehicles. Then, it behaves similarly to Explore screen, but only detects the objects belonging to that mode (e.g. in "find seatings & tables" mode, it only detects chairs, tables, and the like). Additionally, when there's at least one detected object on the screen, the app triggers haptics on an interval (e.g. every 1s) based on the distance of the nearest detected object to the camera; the nearer it is, the shorter the interval.
- OCR Screen: Shows camera feed (1x len). Read aloud scanned text. Note that text that has been read should not been re-read again.
- Currency screen: Shows camera feed (1x len). It behaves similarly to Explore screen, but only detects the Vietnamese currency/paper money. For this, I have collected a dataset at @currency.zip, implement your technique that combines a model with that dataset to get the job done.
- Settings screen: Shows the following settings in the following order: "Ngôn ngữ"/"Language" (dropdown menu with options: "English" (default), "Tiếng Việt"), "Rung"/"Haptics" (pill option, defaults: on; if off, all haptics are disabled), "Tốc độ nói"/"Speech rate" (slider bar), "Đèn chớp"/"Flash" (dropdown menu with options: "Tự động"/"Auto" (default), "Bật"/"On", "Tắt"/"Off"), "Khôi phục cài đặt gốc"/"Reset factory settings" (wide spanning button. if pressed 7 times, it triggers haptics and exit the app, then reset all settings, including the partially blind/totally blind settings; the next time the user opens the app, it's like they open it for the first time, leading to the setup menu). The settings in this screen does not have voice control.
- History screen: shows the scanned objects/texts, each containing: time (hh:mm:ss) and content (object name, or text). Object name needs to be in current language; when language changes, the way object name gets rendered on the screen needs to change as well. It listens to , it triggers haptics and deletes all history. If the user clicks on an object/text, its content is read aloud. While the content is being read aloud, if the user exits the screen or clicks on another object/text, the current read-aloud is interrupted.
