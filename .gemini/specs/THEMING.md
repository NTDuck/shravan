# Theming Specifications

## Overview
The app supports 20 hardcoded color themes. All UI components must derive their colors from the active theme.

## Default Theme
*   **Name**: Neon Hazard (Index 3, zero-based).

## Theme Selection Behavior
*   When a theme is selected:
    1.  The app's color palette updates globally.
    2.  The theme name is spoken in English (regardless of language settings).
    3.  Haptic feedback is triggered.
